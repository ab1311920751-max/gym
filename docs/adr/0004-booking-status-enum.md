# ADR-0004: 订单状态使用枚举统一

## 状态

已采纳

## 上下文

订单状态在 SQL 注释、Entity 字段、Service 逻辑中使用了魔法数字（0/1/2），且 SQL 注释与代码实际含义不一致（SQL 说 0-已预约/1-已取消/2-已签到，代码实际为 0-待支付/1-已支付/2-已取消）。

## 决策

定义 `BookingStatus` 枚举类，统一状态值和语义。所有代码中使用枚举替代魔法数字。

## 理由

- 消除 SQL 注释与代码的语义矛盾
- 编译期类型安全，IDE 自动补全
- 状态转换逻辑可集中在枚举中管理
- 新增状态（如"已签到"）只需扩展枚举

## 后果

- 数据库存储值不变（0/1/2），枚举的 ordinal 与之对应
- MyBatis-Plus 需配置枚举类型处理器
