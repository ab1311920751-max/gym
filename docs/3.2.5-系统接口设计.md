# 3.2.5 系统接口设计

本系统采用前后端分离架构，后端基于 Spring Boot 3 提供 RESTful 风格 API，前端通过 Axios 实例统一调用。所有接口返回统一的 `Result<T>` 响应体（JSON 格式），鉴权通过 JWT Token（`Authorization` 请求头）实现。

## 3.2.5.1 统一响应格式

所有接口响应的 JSON 结构如下：

```json
{
  "code": "200",     // 业务状态码，"200" 成功，"401" 未登录，"500" 系统异常
  "msg": "操作成功",  // 提示信息
  "data": {}          // 响应数据（泛型）
}
```

## 3.2.5.2 用户认证接口（/auth）

### POST /auth/login — 用户登录

- **描述**：用户登录，成功后返回 JWT Token 和用户信息。
- **请求体**：

```json
{
  "username": "admin",
  "password": "123456"
}
```

- **响应**：

```json
{
  "code": "200",
  "msg": "操作成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "username": "admin",
      "role": "admin",
      "balance": 1000.00,
      "vipType": 2,
      "vipExpireTime": "2027-05-25T00:00:00"
    }
  }
}
```

### POST /auth/register — 用户注册

- **描述**：注册新用户（或管理员新增用户）。注册时密码使用 BCrypt 哈希存储。
- **请求体**：

```json
{
  "username": "zhangsan",
  "password": "123456",
  "email": "zhangsan@example.com",
  "phone": "13800138000"
}
```

- **响应**：

```json
{
  "code": "200",
  "msg": "操作成功"
}
```

## 3.2.5.4 课程预约接口（/booking）

### POST /booking/create — 预约课程

- **描述**：用户预约课程（核心抢课接口）。使用 Redisson 分布式锁保证库存安全，锁粒度为课程 ID 级别（`gym:booking:lock:{courseId}`）。临界区内完成：库存校验 → 时间冲突校验 → 原子扣减库存 → 折扣计算 → 生成待支付订单。
- **鉴权**：需携带 JWT Token。
- **请求体**：

```json
{
  "courseId": 1
}
```

- **响应**：

```json
{
  "code": "200",
  "msg": "操作成功",
  "data": "202605252301001"
}
```

### GET /booking/my — 我的预约

- **描述**：查询当前登录用户的所有预约订单。
- **鉴权**：需携带 JWT Token。
- **响应**：

```json
{
  "code": "200",
  "msg": "操作成功",
  "data": [
    {
      "id": 1,
      "bookingNo": "202605252301001",
      "userId": 2,
      "courseId": 1,
      "courseName": "动感单车",
      "realPrice": 79.20,
      "status": 0,
      "createTime": "2026-05-25T23:01:00"
    }
  ]
}
```

### POST /booking/pay/{id} — 余额支付

- **描述**：对待支付订单执行余额扣款，状态从 `PENDING(0)` 流转到 `PAID(1)`。使用 CAS 原子更新防止并发重复扣款。
- **鉴权**：需携带 JWT Token，且仅订单所属用户可以操作。

### POST /booking/cancel/{id} — 取消预约

- **描述**：取消预约订单。已支付订单自动退款，同时回退课程库存。同样使用 CAS 保证并发安全。
- **鉴权**：需携带 JWT Token，且仅订单所属用户可以操作。

## 3.2.5.5 用户与钱包接口（/user）

### POST /user/recharge — 余额充值

- **描述**：用户余额充值。
- **鉴权**：需携带 JWT Token。
- **请求体**：

```json
{
  "amount": 100.00
}
```

### POST /user/buyVip — 购买 VIP

- **描述**：使用余额购买 VIP 会员，支持月卡（vipType=1, 30 元/30 天）和年卡（vipType=2, 300 元/365 天）。采用原子 SQL 一次性完成余额扣减和 VIP 等级更新。
- **鉴权**：需携带 JWT Token。
- **请求体**：

```json
{
  "vipType": 1
}
```

### PUT /user/password — 修改密码

- **描述**：用户修改密码。需校验旧密码正确性，新密码 BCrypt 哈希存储。
- **鉴权**：需携带 JWT Token。
- **请求体**：

```json
{
  "oldPassword": "123456",
  "newPassword": "654321"
}
```

### PUT /user/profile — 修改个人信息

- **描述**：用户修改个人资料（昵称、邮箱、手机号等）。
- **鉴权**：需携带 JWT Token。

### GET /user/list — 用户列表

- **描述**：管理员查看所有用户。

### GET /user/page — 用户分页查询

- **描述**：管理员分页查询用户，支持按用户名搜索。
- **参数**：`pageNum`、`pageSize`、`username`（可选）。

### POST/PUT/DELETE /user — 用户增删改

- **描述**：管理员对用户进行增删改操作。

## 3.2.5.6 支付接口（/alipay）

### GET /alipay/pay — 发起支付宝支付

- **描述**：统一支付入口，支持课程预约支付和余额充值两种模式。
- **参数**：
  - 课程支付：`bookingNo`（订单号）
  - 余额充值：`traceNo`（流水号）、`totalAmount`（金额）、`subject`（标题，可选）
- **返回**：支付宝支付页面的 HTML 表单，浏览器自动跳转到支付宝沙箱收银台。

### GET /alipay/return — 课程支付同步回调

- **描述**：支付宝支付完成后同步跳转回调，由前端 `PaySuccess.vue` 触发。
- **参数**：`out_trade_no`（商户订单号）、`trade_no`（支付宝交易号）。

### POST /alipay/success — 余额充值回调

- **描述**：余额充值成功后由前端 `Wallet.vue` 回调，完成余额入账。
- **鉴权**：需携带 JWT Token，从 Token 中提取用户 ID，防止伪造充值对象。
- **请求体**：

```json
{
  "out_trade_no": "RECHARGE20260525001",
  "total_amount": 100.00
}
```

## 接口设计要点总结

1. **统一响应体**：所有接口返回 `{code, msg, data}` 的 JSON 结构，`code` 为字符串类型（`"200"` 表示成功）。
2. **JWT 鉴权**：登录后获得 Token，前端存入 `localStorage` 并通过 Axios 拦截器自动注入 `Authorization` 请求头。后端 `JwtInterceptor` 解析 Token 后将 `uid` 写入 `RequestAttribute`，Controller 通过 `@CurrentUserId` 注解获取，不可从前端参数取 `userId`。
3. **并发安全**：抢课接口使用 Redisson 分布式锁（`tryLock` + `finally` 释放），支付/取消接口使用 CAS 原子更新（`UPDATE ... WHERE status = 旧状态`）。
4. **状态机**：订单状态遵循 `PENDING(0) → PAID(1) → CANCELLED(2)` 流转，通过 `BookingStatus` 枚举的 `canPay()` / `canCancel()` 方法判定合法转换。
5. **折扣策略**：VIP 折扣通过策略工厂（`DiscountFactory` + `DiscountStrategy`）计算——普通原价、月卡 9 折、年卡 8 折。
